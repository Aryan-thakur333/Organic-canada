## 1. Product Price Amount Convention Proof

* **Analysis of Frontend Formatting Utilities**:
  * [frontend/src/utils/safeNumber.js](file:///D:/eatsie-project/frontend/src/utils/safeNumber.js#L25) divides cents by 100: `safeDivide(safeNumber(cents), 100)`.
  * [frontend/src/utils/productPricing.js](file:///D:/eatsie-project/frontend/src/utils/productPricing.js#L13) converts prices to major units by dividing by 100: `return number / 100`.
  * [frontend/src/utils/b2bQuoteNormalize.js](file:///D:/eatsie-project/frontend/src/utils/b2bQuoteNormalize.js#L108) normalizes minor units by dividing by 100: `const amount = toNumber(amountMinor, 0) / 100`.

* **Analysis of Database Seed Files**:
  * [backend/src/scripts/seed-category-products.ts](file:///D:/eatsie-project/backend/src/scripts/seed-category-products.ts#L31-L98) registers products with prices such as:
    * `"Organic Apples"`: price `499` in `CAD` (Storefront displays `$4.99`).
    * `"Fresh Bananas"`: price `299` in `CAD` (Storefront displays `$2.99`).
    * `"Chicken Breast"`: price `1299` in `CAD` (Storefront displays `$12.99`).
    * `"Cheddar Cheese"`: price `799` in `CAD` (Storefront displays `$7.99`).
  * [backend/src/scripts/seed-subscription-plans.ts](file:///D:/eatsie-project/backend/src/scripts/seed-subscription-plans.ts#L6-L10) seeds subscription plan pricing such as:
    * `"Weekly Plan"`: amount `1999` in `CAD` (Storefront displays `$19.99`).
    * `"Monthly Plan"`: amount `6999` in `CAD` (Storefront displays `$69.99`).
    * `"Yearly Plan"`: amount `69900` in `CAD` (Storefront displays `$699.00`).

* **Conclusion**:
  * **Product prices are stored as minor units (cents) on the backend database** (e.g., $1.00 is stored as `100`).
  * In contrast, shipping options in `seed.ts` were seeded as `10`, which represents `$0.10` or a minor units developer omission, but the storefront adapts dynamically.
  * To preserve the correct product pricing system, the pricing importer script has been locked to process CSV uploads using **minor units (cents)**.

## 3. Original Build Errors & Root Causes

* **Error**: `Property 'prices' does not exist on type 'ProductVariant'`
  * **Root Cause**: The Medusa `ProductVariant` type generated by the ORM does not declare `prices` because variant pricing is linked externally in Medusa v2.
  * **Fix**: Declared a local interface `AuditedProduct` / `AuditedVariant` with `prices` and cast the result of `query.graph` queries.

* **Error**: `Property 'listPersonalizationTemplates' does not exist on type '{}'`
  * **Root Cause**: Resolving `PERSONALIZATION_MODULE` or `"personalizationModuleService"` from container via untyped keys maps to the default `{}` empty object type.
  * **Fix**: Cast the resolved container service reference explicitly using the concrete type `PersonalizationService`.

* **Error**: `Argument of type ... is not assignable to parameter of type 'never'`
  * **Root Cause**: Initializing arrays as `const results = []` without types causes TypeScript to infer the type as `never[]`.
  * **Fix**: Created structured types (`PriceGapMissing`, `PriceGapReport`) and explicitly typed the arrays.
